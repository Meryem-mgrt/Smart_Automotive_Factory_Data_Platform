# ADR 0001 — Choix de la stack

- Statut : proposé
- Décision : MQTT (Mosquitto) + FastAPI + PostgreSQL + Airflow + DBT + Odoo Community, le tout en Docker Compose.
- Raisons : briques open source, courantes en entreprise, adaptées à un profil Data Engineer.
- À trancher : LLM du chatbot (API ou Ollama), framework mobile (Flutter ou React Native).
